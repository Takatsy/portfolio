Application web pour l'Université de Toliara : les étudiants s'inscrivent en ligne, et l'administration dispose de données fiables et traçables. J'en développe les deux parties : l'API en Python et l'interface en React.

Architecture

  1. Interface ReactCe que l'étudiant utilise pour s'inscrire
  2. API REST, Django REST FrameworkReçoit, valide et fournit les données
  3. Base de donnéesConserve les inscriptions de façon fiable

Côté API (Python)

class InscriptionViewSet(viewsets.ModelViewSet):
    queryset = Inscription.objects.all()
    serializer_class = InscriptionSerializer
    permission_classes = [IsAuthenticated]

    def perform_create(self, serializer):
